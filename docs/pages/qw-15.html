Quick win 15 of 20 · A main heading on every page

What we're proposing

Give every page template one H1, with the headings below it in order.

Why

The homepage and the Chambers Wharf page have no H1. Their first headings are H2s, or text set in the hero.

Quick win 15

A main heading on every page

One H1 per page, so screen readers and search engines know what the page is.

Try: Compare the two heading outlines.

Today

  1. H2 Reconnecting London with the River Thames
  2. H2 London's super sewer is now protecting the river from pollution.
  3. H3 Latest News
  4. H3 Tideway's commitment on modern slavery

No H1 on the page

Proposed

  1. H1 London's super sewer is protecting the Thames
  2. H2 2025, the first full year
  3. H2 What would you like to do?
  4. H2 Latest news
  5. H3 New report reveals positive impact…

BehaviourA template change rather than a content change, so it fixes every page that uses the template.
